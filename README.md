## 📊 Featured Projects

### 🚢 [OceanLink Global Logistics & Port Operations Analytics](https://github.com/RAHUL20052005/OceanLink-Logistics-Analytics)

End-to-end analytics on **126,000+ rows from 10 source files**: cleaned in Python, loaded into a SQL Server database, and delivered through Power BI and Tableau dashboards.

| | |
|---|---|
| **Problem** | No single view of shipments, ports, carriers and costs |
| **What I built** | SQL Server database with keys and validation checks, 12 analytical queries, 9 reporting views, 6 Power BI pages, 5 Tableau dashboards |
| **Key results** | 84.75% on-time delivery across 20,000 shipments; customs holds cause 77% late deliveries; customs fees are about 76.5% of logistics cost |
| **Tools** | Python, SQL Server, Power BI, Tableau |

### 🛒 [Retail Chain Profit Leakage & Demand Optimization](https://github.com/RAHUL20052005/Retail-Profit-Leakage)

Analysis of where a retail chain loses profit, which vendors miss their SLA, where stockouts happen and which products to promote.

| | |
|---|---|
| **Problem** | Margin was being lost with no clear view of where |
| **What I built** | Loss driver analysis, vendor SLA scorecard, stockout hotspot analysis, SKU margin and return ranking, operational and executive dashboards |
| **Key results** | Discounts are the biggest leak (Rs 3.56M), followed by cancelled orders (Rs 1.66M) and approved returns (Rs 1.54M); identified the 3 worst vendors and the top 5 SKUs to promote |
| **Tools** | Python, SQL, Power BI, Tableau |
